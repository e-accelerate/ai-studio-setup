Multimodal infrastructure / Personal lab

One workstation, several AI workflows

EnvironmentRTX PRO 5000 / 48 GB

FocusLanguage, image and video

MeasurementMixed cold / warm timings

The problem

Running several AI workflows on one workstation requires managing a constrained memory budget and different serving stacks. The intended result is usable endpoints and tools for a coding agent or chat application.

Engineering focus

The existing setup describes Qwen3.8-27B on SGLang with NVFP4 weights, a DFlash2 speculative drafter and vision support. Image generation and editing use Qwen-Image. Video generation is also reported, but the video model is not identified on the original page.

Reported language performance

The original portfolio reports 300+ generated tokens per second, 6,073 prompt tokens per second on a 22,000-token prompt, and 3.7 seconds to first token on that prompt. It lists a 262,144-token context window; this does not establish performance across the full context window or under concurrent requests.

Reported creative workflow timings

The page reports an 18-second 1536×864 image, an 8-second image edit, a 26-second 1024×1024 transparent PNG, and a 34-second five-second video with sound at 864×480. Image times include cold startup; the video time is warm. These are separate workload measurements, rather than evidence that all services run concurrently.

Evidence and limits

This case study preserves the published figures without adding new measurements. Request payloads, software versions, repeated trials and output samples are not yet included here. A client deployment needs its own quality checks, memory measurements and workload timings.

Why it matters

A single workstation can support several application types when the serving and switching workflow fits its resources. The right comparison is the complete user task, including loading, generation and delivery of the output.

Source: measurements described in the original eAccelerate portfolio. This is personal lab work; no client engagement or testimonial is implied.
