# eAccelerate portfolio

Static portfolio for independent private AI consulting, hosted on GitHub Pages.

## Pages

- `index.html`: positioning, selected lab work, engagement approach, about and contact.
- `services.html`: existing fixed-price service catalogue and commercial terms.
- `case-cluster.html`: two-box cluster performance investigation.
- `case-startup.html`: model startup timing improvement.
- `case-workstation.html`: multimodal workflows on a 48 GB workstation.
- `styles.css`: shared responsive styling; no build step or JavaScript required.

## Preview

Run `python3 -m http.server 8000` from this directory and open http://localhost:8000.

## Content integrity

Case studies describe personal lab work. Measurements describe the consultant’s own hardware and workloads.
Keep model, hardware and timing conditions alongside performance figures.
Before strengthening these claims, add benchmark logs, model and engine revisions,
reference links, evaluation details and actual demo assets.

The site does not invent clients, testimonials, qualifications or contact details.
Contact remains [@EAccelerate_42 on X](https://x.com/EAccelerate_42).

## Positioning and services

Focus: private AI deployment and optimisation on Apple Silicon, DGX / GB10 and
RTX, including native Apple apps and workflows using private models. The services
page leads with fixed-price packages, followed by five compact expandable options
for larger engagements. Generic strategy, forecasting and unrelated advisory
capabilities are removed. Service tables stack into readable cards below 700px.

## Apple application work

`apple-apps.html` describes ModelDeck iPhone/iPad functionality confirmed in the local
SwiftUI and MLX sources and development records. MacBook applications and MacBook
MLX usage are included from the developer’s account. No App Store publication or
new cross-device benchmark is claimed. Local model execution and remote generation
services are distinguished.

## Featured demo

`assets/modeldeck-demo.mp4` is the provided Accelerate_ModelDeck-Promo-Final.mp4
remuxed without re-encoding for progressive playback (MP4 faststart). Existing
scenes, audio and privacy cuts are preserved. The video appears on the homepage
and Apple apps page, with native controls, a poster and no autoplay or preload.
